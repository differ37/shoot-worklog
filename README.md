# 🎬 촬영 업무일지

메모장에 적던 촬영 업무일지를 그대로 붙여넣으면 **수입 · 입금/미입금 · 일정 · 통계**를 한눈에 정리해 주는 웹페이지입니다.

- 총 수입, 입금 완료, 아직 못 받은 돈, 평균 일당, 평균 근무시간
- 월별 수입 차트(입금/미입금), 받을 돈 목록(경과일 표시), 작업 달력
- 제작사·작품별 수입, 함께한 촬영감독, 요일별 촬영일
- 목록에서 **입금 확인**을 누르면 메모의 `미결`이 `결제완료`로 바뀜

## 데이터 (노션 동기화)
업무일지 원본은 **노션 페이지**에 있고, `worker/`의 Cloudflare Worker가 노션 API로 읽어 사이트에 전달합니다.
노션 토큰과 사이트 비밀번호는 Worker 비밀값(`NOTION_TOKEN`, `PASSCODE`)으로만 저장되어 이 저장소에는 없습니다.
사이트에서 `입금 확인`을 누르면 노션 페이지의 `미결`이 `결제완료`로 바뀝니다.

## 메모 형식
```
9/22~24(화수목)결제완료
제작사/작품명            (// 도 가능)
촬영감독 퍼스트
22:장소(50) 0820집합, 2330종료     ← (50) = 50만원
23:장소(45) 0940집합, 2420종료
010-0000-0000 PD이름
ㅡ 메모

10/30(금)미결
제작사 // 작품명
장소
10:00~26:30
견적 500,000
```
